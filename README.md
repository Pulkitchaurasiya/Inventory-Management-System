Inventory Management System for SMEs

A web-based Inventory Management System designed for Small and Medium Enterprises (SMEs) to manage, track, and organize their inventory efficiently. The project provides a simple and user-friendly interface for monitoring products and stock information.

📌 Project Overview

The Inventory Management System for SMEs is developed to simplify day-to-day inventory management. It helps businesses keep track of products, monitor stock levels, and manage inventory-related information through an easy-to-use web interface.

This project was developed as a front-end web development project using HTML, CSS, and JavaScript.
