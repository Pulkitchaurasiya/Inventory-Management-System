About Project

Final Year Project — Inventory Management System

InvenPro — Inventory Management System

A comprehensive, full-featured inventory management web application built as a Final Year College Project. Designed to simulate real-world business software used by small and medium enterprises.

HTML5 CSS3 JavaScript Chart.js Font Awesome

Key Features

Secure Login

JS-based authentication with form validation and session persistence.

Live Dashboard

Real-time stats with animated cards, Chart.js charts, and alerts.

CRUD Products

Full add, edit, delete, search, and filter functionality.

Inventory Control

Stock in/out operations with movement log and low-stock warnings.

Sales Reports

Track revenue, orders, and best-selling products with charts.

Dark Mode

Complete dark/light theme toggle with smooth transitions.

LocalStorage

All data persists across sessions using browser localStorage.

Responsive

Fully responsive design for desktop, tablet, and mobile.
